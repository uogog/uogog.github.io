gdb用于调试C程序 链接到标题

常用指令

gdb <可执行文件> # 注意这里的可执行文件一定要用 -g参数生成的
list <number> #看源文件的
b [{num|函数名}] if i=4 && i!=2 #设断点
r [参数] # 开始执行
n # 下一行
s # 进入函数
p # 查看变量
display # 一直查看变量
undisplay # 取消一直查看
c # 运行到断点
q # 退出
f # 跳出函数
set args # 设置参数 和 r 【】 一样效果
info b # 看所有断点
ptype # 看变量类型
bt # 看栈帧
frame # 切换栈帧
